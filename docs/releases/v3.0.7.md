# AgentStreamDeck v3.0.7

[Project overview](../../README.md) · [Documentation index](../README.md)

Ask Jelly for a coffee break with five taps within one minute.

- Five Jelly presses within a rolling 60-second window start the existing pointing, rainbow and steaming-coffee routine early.
- During any coffee invitation, pressing either Jelly or the cup opens Ryan’s Buy Me a Coffee page and dismisses the invitation. The fifth tap only presents the invitation.
- Requires two unassigned keys and respects the coffee opt-out, update priority and agent controls.
- Invitations still expire after 60 seconds and reschedule the random 1–3 hour timer. Tap counts reset when an invitation starts or ends.
- Serial and key-ownership checks reject repeated, expired or reassigned invitation presses so one invitation opens at most one browser request.
- Updates the README and Jelly guide with the new gesture.
