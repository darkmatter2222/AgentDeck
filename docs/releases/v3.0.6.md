# AgentStreamDeck v3.0.6

A calmer, clearer update invitation from Jelly.

- Shows “Update available” on two readable lines beneath Jelly, with a red exclamation point and a softly pulsing green upgrade arrow above him.
- Gently cycles Jelly's body through rainbow colors while keeping eyes, outlines and text legible.
- Replaces constant travel with a breathing pose and at most one hop every 30 seconds. Ordinary agent reactions cannot add extra update-mode hops.
- Reserves space for the label on 72, 80 and 96 pixel keys. Shows “Updating / please wait” during installation.
- Preserves one-touch update installation, automatic broker restart and agent-key priority.
- Adds a README animation rendered from the real device loop and regression coverage of native-size rendering, movement limits, update actions and agent assignment.

Normal Jelly behavior returns when the update indicator is inactive. Update detection alone never installs a package.

## Documentation

- Rebuilds the README around developer benefits, a four-step setup, integration coverage, customization and Jelly.
- Moves detailed Jelly settings and maintenance instructions into dedicated guides, keeping release history in release notes.
- Refreshes the documentation index and removes version branding from the hero animation. The hero generator now updates only its image, so regenerating it cannot overwrite README edits.
- Uses `python -m ocdeck` throughout the quick start to avoid Windows Scripts-directory PATH issues.
