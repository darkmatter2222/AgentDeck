# AgentDeck v2.0.0 — Make every key your own

Your six-key mission control now includes customizable artwork, official harness
icons, smoother animation, and managed HomeAILab launchers.

## What's new

- **Smoother motion:** 96-step time-based animation, targeting 24 FPS on new
  installations, with configurable speed, intensity, glow, and per-button dimming.
- **Your own button designs:** Classic, Harness, and Minimal layouts; five themes;
  configurable text lines, aliases, scrolling, shimmer, text size and alignment.
- **Official harness icons:** bundled OpenCode, Claude, Copilot, Gemini, and Cursor
  assets. Status dots, rings, and pills stay separate from the logo.
- **More styling:** solid/double/corner borders, gradient/grid backgrounds, logo
  sizes, and Studio, Neon, Focus, Readable, and Marquee presets.
- **Focus corrections:** attach to both target and foreground GUI threads, restore
  minimized windows, preserve the focused input child, and verify keyboard focus.
- **HomeAILab integration:** run existing BAT launchers inside a managed AgentDeck
  window. Prevent nested OpenCode shim launches from creating a second window.
- **Simpler launch examples:** local Claude, cloud Claude/OpenCode, and HomeAILab
  5090, Spark, and cluster wrappers through `Launch-Agent.bat` / `ocdeck start`.
- **Expanded documentation:** visual galleries, animated comparisons, configuration
  recipes, and local/cloud launcher setup in the README.

## Download and upgrade

Download **AgentDeck-v2.0.0.zip** and its companion SHA-256 file below. The ZIP is a
complete source distribution with scripts, icons, and documentation, not a
standalone EXE. Extract to your permanent AgentDeck directory. Keep the same path
because installed hooks reference source files there; stop the broker before
replacing a running checkout and preserve your per-user configuration.

**Restart the broker after upgrading. Relaunch unmanaged sessions through the new
wrappers to enable reliable window mapping.** Restarting the broker alone cannot
assign a managed window title to an already-running external launcher.

Existing appearance settings and explicit FPS values are retained. To opt into
new styling and the 24 FPS target:

```powershell
python -m ocdeck appearance --preset studio --fps 24
```

Restart the broker after saving settings. For HomeAILab:

```powershell
cd C:\Projects\MyApp
C:\Tools\AgentDeck\scripts\Launch-Agent.bat --profile opencode --launcher "C:\Tools\HomeAILab\harness\opencode\opencode-5090.bat" --
```

Complete the OpenCode installation or corresponding project hook setup first.
The wrapper preserves the HomeAILab script's model settings and permission flags.

## Validation and limitations

The release workflow verifies source checksums and runs the Python and JavaScript
suites before publication. Pre-release validation: **42 Python tests and 20
JavaScript tests passed**. Focus regressions use mocked Win32 APIs; physical Mini
throughput, Windows foreground behavior, and live HomeAILab/local/cloud acceptance
still require testing on your machine. No new hardware validation is claimed.

Windows desktop, Stream Deck Mini, Python 3.11+, Windows Terminal, and Node.js 20+
remain required for the supported setup. Hook coverage varies by harness; a
non-red button does not prove that no approval is waiting. Key presses only
request focus. They do not type or approve tools. VS Code remains an isolated-profile
preview integration. Remote relays and other Stream Deck models remain unsupported.

AgentDeck code is Apache-2.0; third-party icon attribution is included.
