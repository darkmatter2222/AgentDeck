# AgentDeck v1.0

[Project overview](../../README.md) · [Documentation index](../README.md)

Six Stream Deck Mini keys for your coding agents. See reported activity at a glance,
then press a key to focus the corresponding managed window.

## Included integrations

- **OpenCode:** global server plugin and an optional TUI adapter.
- **Claude Code:** native project hooks and a Windows BAT launcher.
- **GitHub Copilot CLI:** native project hooks and a Windows BAT launcher.
- **Copilot in VS Code:** preview integration using an isolated editor profile.
- **Gemini CLI:** native project hooks and a Windows BAT launcher.
- **Cursor CLI (`agent`):** native project hooks and a Windows BAT launcher.

All integrations share one local broker and six stable assignments. Additional
launches wait for a vacancy. Closing an agent releases its key without moving the
others. Key presses request focus only; they never approve tools or type answers.

## What's in the release

- Direct USB HID control of the six-key Stream Deck Mini.
- Animated running, idle, identified-input, unknown and READY indicators.
- Managed launch identities, broker reconnection and pending-state recovery.
- Hook installation with backups, dry-run preview and removal that preserves
  unrelated settings.
- Setup tutorials for existing installations, fresh OpenCode installations and a
  foreground broker without OpenCode.
- Troubleshooting, architecture/API documentation and physical acceptance steps.

## Download and start

Download **AgentDeck-v1.0.zip** below and extract it to a permanent directory such
as `C:\Tools\AgentDeck`. This is a complete **source distribution**, with scripts
and documentation; it is not a standalone EXE. Python dependencies are installed
by the documented setup process.

- [Choose your setup path](https://github.com/darkmatter2222/AgentDeck/blob/v1.0/docs/TUTORIALS.md)
- [Harness support and limitations](https://github.com/darkmatter2222/AgentDeck/blob/v1.0/docs/HARNESSES.md)
- [Documentation index](https://github.com/darkmatter2222/AgentDeck/blob/v1.0/docs/README.md)
- [Demo video](https://www.youtube.com/watch?v=NTWLbLbJiO0)

Requirements: Windows desktop, Stream Deck Mini, Python 3.11+, Windows Terminal,
and Node.js 20+ for the new hook adapters. Your chosen harness must be installed
and authenticated. Release the Mini in Elgato's device preferences before using
AgentDeck. The original automatic installer requires OpenCode; the tutorials also
cover a foreground setup without it.

The companion `.sha256` asset verifies the ZIP; `SHA256SUMS.txt` inside the archive
lists checksums for the tracked source files.

## Validation and known limitations

**25 Python tests and 20 Node tests passed**, including real subprocess/loopback
integration, broker restart recovery, concurrent hooks and cleanup. Native harness
loading, Windows scripts, physical USB and foreground activation remain local
acceptance gates; see the included verification record.

Approval visibility differs by harness. OpenCode tracks identified permissions and
questions. Claude tracks identified question calls; permission notifications
without paired IDs can show unknown. Copilot and Cursor activity does not provide
complete approval tracking. Missing hooks can leave the last reported state.

VS Code uses fresh isolated user data per launch and may require sign-in. Cursor
desktop, Codex CLI, Aider, remote/WSL/container relays and non-Mini hardware are not
included. Linux/macOS support software/status testing, not Windows desktop focus.
