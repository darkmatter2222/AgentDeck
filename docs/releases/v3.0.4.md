# AgentStreamDeck v3.0.4

Jelly responds to your touch and occasionally invites you for a coffee.

- Tap an ordinary Jelly key for a playful animation and a short response, including Boop!, Ouch!, Hehe!, Hey! and Tickles! Reactions work with ambient thoughts disabled.
- Every random 1–3 hours, two unassigned keys can host a 60-second coffee invitation. Jelly points toward the other key, says Coffee?, and cycles through rainbow body colors. The official Buy Me a Coffee cup has animated steam.
- Tap the cup to open https://buymeacoffee.com/j6oiubzfnh in your default browser and dismiss the invitation. No browser opens without a press. No payment is initiated.
- Agent assignments immediately cancel an invitation that loses either key. Other free buttons remain available. Coffee can use nonadjacent keys. Timers restart on broker startup and reschedule after dismissal or expiry.
- Pressing a minimized agent window now requests maximize and waits for the asynchronous Windows transition before bringing it to the foreground. Other window sizes stay unchanged.
- Button routing now uses the displayed action and slot generation. Update badges retain their install action through the worker queue; they cannot intercept a freshly assigned agent key.
- New `jelly.coffee` and `jelly.coffee_rainbow` settings both default to true. The existing Jelly and animation switches remain respected.
- Updated README animation, artwork attribution and troubleshooting instructions. Button-down routing is logged without window titles.

Validation: 137 Python tests, 27 Node tests, Ruff, Pyright and package build locally; Windows and Ubuntu CI with Python 3.11/3.13 before merge. Physical Stream Deck and Windows desktop acceptance still requires the user's hardware.

Upgrade the package, restart the broker, and restart coding clients that still have an old window mapping. Existing native harness integration and the `ocdeck` command remain compatible.
