# AgentStreamDeck 3.0.0 — Meet your coding Jelly

[Project overview](../../README.md) · [Documentation index](../README.md)

Your coding companion now lives on your Stream Deck, enabled by default.
Jelly rests at the bottom of an unused button, explores his little home, reacts
to your agents and shares an occasional thought above his head.

## A pet with personality

- 33 visible actions, 33 body poses and 14 hop styles, including local scooting,
  crawling, rolling, dancing, stretching and melting into a sleepy puddle.
- 23 moods with changing colors, four personality presets and six simulated needs.
  Coding activity metadata feeds and exercises Jelly; idle time makes him sleepy,
  while sustained workload can make him overworked. No source code or prompts are read.
- Attention-aware looks, pointing and safe approaches to free keys near agents
  needing input. Explicit success and failure events get their own reactions.
- 1,040 offline authored thoughts, with scrolling text above his head and bounded
  repetition history. No cloud connection or language-model dependency.
- Floor-anchored resting poses, seamless deck-space motion, and agent controls
  taking priority whenever a button is assigned.

## Upgrade

Install the wheel below or run `python -m pip install --upgrade agentstreamdeck`
once the matching PyPI publication completes. Configuration is preserved. Jelly
starts automatically when animations are enabled and an unused key is available.
Existing `"jelly": {"enabled": false}` settings remain off. Use the same setting
to disable him. Persistence remains optional and off by default.

The release includes the wheel, source archive, repository ZIP, SBOM, checksums,
and an HD authored Jelly product animation. The animation uses actual runtime
renderers on a simulated Mini; it is not physical hardware footage. Python and
Node suites, lint, formatting, types and package builds gate publication.
Physical Mini/Mk.2/XL acceptance still requires hardware testing.
