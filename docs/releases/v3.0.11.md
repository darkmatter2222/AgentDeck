# AgentStreamDeck v3.0.11: Jelly's living world

Jelly now celebrates holidays, dresses up, reacts to local weather and enjoys seasonal activities across your unused Stream Deck keys.

- **75 configurable scenes**, including 50 additional festival, birthday, seasonal and weather experiences.
- July Fourth fireworks/fountains/smoke, Thanksgiving food, Christmas lights/Santa/elves/snow, Holi colors, Easter eggs and Halloween ghost/skeleton/mask/reaper costumes.
- Year-specific festival dates, cross-year windows, holiday priorities, birthday support, northern/southern seasons and quiet hours.
- Approximate automatic IP location, explicit coordinate/timezone/country overrides, current temperature captions, day/night context and bounded background weather requests.
- Independent toggles for scenes, weather, holidays, seasons, props, particles, costumes, captions, help and reduced motion.
- `ocdeck world configure/show/catalog/validate/preview`, with atomic `jelly.ini` configuration and offline scene previews.
- Hold Jelly for setup guidance, then hold again to open the fixed repository documentation page. Stale key reassignment cancels the action.
- A repository-wide UI/UX and implementation contract linked from `AGENTS.md`, plus complete setup/reference/catalog documentation and generated previews.

Agent ownership, ready keys, controls menus, update handling and coffee interludes retain precedence. Scenes adapt to Mini, Original/MK.2 and XL; props shrink with one free key and disappear with no space. Existing direct-tap behavior is retained when world help is disabled; when enabled, short taps dispatch on release to distinguish a hold.

Weather/location are enabled by default. Use `ocdeck world configure --no-weather --no-auto-location` for an offline world. The bundled providers have their own usage terms; no agent content is sent. Tornado and hurricane animations are explicitly selected demos, not inferred emergency alerts. Festival regional conventions and provider details are documented in the guide.

Validation: local Python and Node suites, type/lint/format checks, documentation links, package build, scene previews and simulated 6/15/32-key ownership tests. Live provider access could not be verified from the development workspace. Physical USB timing and real-device interaction still require hardware validation.
