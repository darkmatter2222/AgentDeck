# AgentStreamDeck v2.1.1

AgentDeck is now **AgentStreamDeck**. This release retains all 20 enhancements
from [v2.1.0](v2.1.0.md), including alerts, diagnostics, redacted reports, larger
decks, Codex support, appearance sharing, CI and signed package publishing.

- Rename the Python distribution to `agentstreamdeck` and bump to 2.1.1.
- Update current README, guides, package URLs, update checks and visible messages.
- Preserve `ocdeck`, config locations, installed hooks and Windows identities.
- Document repository settings and exact revised PyPI trusted publisher values.
- Produce new wheel, source archive, ZIP, SBOM, checksums and provenance.

See [migration instructions](../RENAMING.md). Uninstall the old `agentdeck`
distribution before installing the new one; both provide `ocdeck`.
PyPI requires owner-side setup and a successful publishing workflow. Mock tests
do not replace live Windows toast, device or adapter acceptance testing.
