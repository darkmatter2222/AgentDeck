# AgentDeck v2.1.0 — More agents, better visibility

[Project overview](../../README.md) · [Documentation index](../README.md)

Twenty enhancements expand AgentDeck beyond the Mini, add Codex and optional
alerts, and make setup, troubleshooting and maintenance easier.

## Enhancements

1. **Sound alerts:** optional system chime/custom WAV, state selection, cooldown and slot muting.
2. **PR CI:** Python/Node tests on Windows/Ubuntu and Python 3.11/3.13, plus packaging checks.
3. **Windows toasts:** identified-input notifications with snapshot deduplication and interruption checks.
4. **Doctor:** actionable PASS/FAIL/MANUAL diagnostics, JSON output and no-device mode.
5. **Issue reports:** redacted status, versions, configuration and log excerpts in a ZIP.
6. **Structured logs:** rotating JSON, correlation IDs and recent error excerpts in status.
7. **Scrubbing tests:** randomized metadata, rendered-label, log and report coverage.
8. **Release notices:** background, offline-safe checks with notes and a disable option.
9. **Pre-commit:** Ruff lint/format and per-file Node syntax checks.
10. **Larger decks:** 6-key Mini, 15-key Original/MK.2 and 32-key XL, automatic slots and overflow promotion.
11. **Codex CLI:** project hook merge/receipts, managed CLI/BAT launchers and live-test runner.
12. **Input counts:** known counts display 1–9 or 9+; unknown totals remain unknown.
13. **Type gate:** Pyright basic across the Python package.
14. **Python distribution:** complete wheel/sdist, SBOM/checksums, provenance and PyPI trusted-publishing workflow.
15. **Uninstall:** receipt discovery, dry-run, preflight, unrelated-hook preservation and backups.
16. **Actionable errors:** AD error codes, fix/check commands and documentation links.
17. **High contrast:** sixth palette with renderer gallery and contrast coverage.
18. **Appearance dry-run:** settings diff and in-memory example preview; zero writes.
19. **Appearance sharing:** validated versioned JSON import/export.
20. **Elgato conflict detection:** conservative process guard before opening HID and doctor coverage.

The README documents every feature, command, configuration default and limitation.
A Windows CI failure also led to a native-EXE argument-quoting fix.

## Install or upgrade

Download **AgentDeck-v2.1.0.zip** for the complete source, scripts and documentation.
Close managed sessions and stop the broker before replacing/updating an existing
permanent checkout. Run the original `scripts/Install.ps1` for OpenCode/task setup,
or reinstall the package into your foreground environment. Reinstall affected
project hooks and restart the broker and managed sessions. Configuration is retained.

The wheel is also available for installation with `python -m pip install <wheel>`.
Python 3.11+, Node 20+ and an installed supported harness are required. Dedicated
Windows focus requires Windows Terminal. PyPI publishing requires the account-side
setup in [docs/PYPI.md](https://github.com/darkmatter2222/AgentDeck/blob/main/docs/PYPI.md);
this GitHub release does not imply the package is already published on PyPI.

## Validation and limits

The implementation passed 61 Python tests and 25 Node tests on all four
Windows/Ubuntu Python combinations, plus lint, formatting, type and packaging
checks. The release workflow repeats tests and verifies checksums before publishing.

Physical USB on Mini/MK.2/XL, interactive Windows focus/toasts/Focus Assist/task
cleanup, and provider-backed Codex hook execution still require local acceptance.
Hosted CI uses fixtures/mock hardware. Sound/toasts default off; toasts require
identified requests, and deduplication resets when the broker restarts. Codex
approval counts remain unknown. One broker controls one deck; keys represent
agents/focus rather than arbitrary custom actions. Uninstall retains backups,
logs and the Python environment. See the README and docs/NEXT.md for full details.

## Downloads and integrity

Assets include source ZIP, Python wheel/sdist, CycloneDX SBOM and SHA256SUMS.txt.
Build provenance is recorded through GitHub artifact attestations. Download the
assets together and run `sha256sum --check SHA256SUMS.txt` to check integrity.
